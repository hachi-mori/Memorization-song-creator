# Scene（画面）設計

## Scene一覧

| Scene名 | 目的 | 主な入力 | 主な出力 |
|---------|------|----------|----------|
| Scene1 | トップ画面（メニュー） | ボタンクリック | 画面遷移 |
| Scene2 | 語句入力 | スプレッドシート編集、CSVファイル | CSVファイル保存（lyrics/） |
| Scene3 | 覚え歌生成 | 語句・楽曲・キャラ選択 | 生成楽譜（CreatedScores/）、音声（Voice/） |
| Scene4 | 再生 | 音声ファイル選択 | 音声再生 |
| CreditScene | クレジット表示 | 戻るボタン | 画面遷移 |

## Scene遷移

### 遷移ルール
- **Scene1**: すべてのSceneの起点（メニューハブ）
- **Scene2/Scene3/Scene4**: 相互に直接遷移可能（左サイドボタン）
- **Scene1**: 常に戻れる（左下ボタン）
- **CreditScene**: Scene1からのみ遷移、Scene1にのみ戻る

## 各Sceneの詳細

### Scene1（トップ画面）

#### 目的
- アプリケーションのタイトル表示
- 主要機能へのナビゲーション

#### UI要素
- タイトルロゴ（拡大・回転アニメーション）
- 背景画像
- ボタン:
  - **「はじめる」** → Scene2へ遷移
  - **「クレジット」** → CreditSceneへ遷移
  - **「フルスクリーン/ウィンドウ」** → 表示モード切り替え
  - **「終了」** → アプリケーション終了

#### 状態
- `scale` / `scale2`: ロゴ拡大率（アニメーション用）
- `rotationAngle`: ロゴ回転角度（アニメーション用）
- `audioplay`: BGM再生状態
- `ScreenName`: 現在の表示モード名（"ウィンドウ" / "フルスクリーン"）

#### イベント
- マウスクリック（各ボタン領域）
- フルスクリーン切り替え

#### ビジネスロジック
- なし（純粋なナビゲーション画面）

### Scene2（語句入力画面）

#### 目的
- 覚え歌に使用する語句をスプレッドシート形式で入力・編集
- CSVファイルとして保存・読み込み

#### UI要素
- **スプレッドシート**（4列 × 可変行）:
  - 列1: 番号
  - 列2: 単語
  - 列3: 読み（ひらがな/カタカナ）
  - 列4: 文字数
- **ボタン**:
  - **「行追加」** - 新しい行を追加
  - **「行削除」** - 選択行を削除
  - **「保存」** - CSVファイルに保存（`App/lyrics/`）
  - **Scene1/Scene3/Scene4への遷移ボタン**
- **ファイルリスト** - 既存のCSVファイル一覧（読み込み用）
- **ファイル名入力欄** - 保存時のファイル名指定

#### 状態
- `table`: スプレッドシートデータ（SimpleTable）
- `activeIndex` / `nextActiveIndex`: 編集中セルの位置
- `textEditState`: セル編集状態
- `listBoxState`: ファイルリスト選択状態
- `invalidRows`: 入力エラーのある行番号リスト
- `saved`: 保存成功フラグ
- `SaveMassage`: 保存メッセージ
- `MessageOpacity`: メッセージ透明度（フェードアウト用）

#### イベント
- **セルクリック** → セル編集モード
- **「保存」ボタン** → CSV保存（`App/lyrics/ファイル名.csv`）
- **ファイル選択** → CSV読み込み → スプレッドシート表示
- **「行追加/削除」ボタン** → テーブル更新
- **スクロール** → tableScrollBar操作

#### データ処理
- **保存**: SimpleTable → CSV形式 → ファイル書き込み
- **読み込み**: CSVファイル → SimpleTable表示
- **検証**: 文字数の一致チェック（単語と読みの文字数）

#### ビジネスロジック
- 文字数不一致の行を`invalidRows`に記録し、赤色で表示

### Scene3（覚え歌生成画面）

#### 目的
- 語句・楽曲・キャラクターを選択し、覚え歌を生成
- 語句と楽曲の一致率を表示

#### UI要素
- **リストボックス × 3**:
  1. **語句選択** - `App/lyrics/` 内のCSVファイル一覧
  2. **楽曲選択** - `App/OriginalScores/` 内のJSON楽譜一覧
  3. **キャラクター選択** - VOICEVOX話者一覧（四国めたん、ずんだもん、春日部つむぎ）
- **円グラフ** - 語句と楽曲の一致率表示
- **キャラクタープレビュー**:
  - キャラクター画像
  - サンプル音声再生（"ららららら"）
- **ボタン**:
  - **「生成」** - 覚え歌生成・音声合成
  - **Scene1/Scene2/Scene4への遷移ボタン**
- **ローディング画面** - 生成中の表示（回転アニメーション）

#### 状態
- `listBoxState1/2/3`: 各リストボックスの選択状態
- `lyricsfileNames`: 語句ファイル名リスト
- `OriginalScoresfileNames`: 楽曲ファイル名リスト
- `speakers` / `speakerIDs`: VOICEVOX話者情報
- `isloading`: 生成処理中フラグ
- `task`: 非同期タスク（AsyncTask<bool>）
- `Difference`: 類似度（語句と楽曲の不一致度）
- `differenceScorePairs`: 類似度と楽曲のペアリスト
- `Character`: 選択中のキャラクター番号
- `audio1/2/3`: キャラクターサンプル音声
- `values`: 円グラフ用の値（一致率、不一致率）
- `saved`: 保存成功フラグ
- `MessageOpacity`: メッセージ透明度

#### イベント
- **リストボックス選択変更** → プレビュー更新
- **キャラクター選択** → 画像・サンプル音声変更
- **「生成」ボタン** → 非同期タスク起動
  1. CSVと楽譜を読み込み
  2. 歌詞を楽譜に割り当て（`UpdateJSONFromCSV`）
  3. 生成楽譜を保存（`App/CreatedScores/`）
  4. VOICEVOX音声合成（`SynthesizeVoiceFromScore`）
  5. 音声を保存（`App/Voice/`）

#### データ処理フロー
```
[語句CSV] + [元楽譜JSON]
    ↓
UpdateJSONFromCSV()
    ↓
[生成楽譜JSON] → App/CreatedScores/
    ↓
VOICEVOX::SynthesizeVoiceFromScore()
    ↓
[音声WAV] → App/Voice/
```

#### 非同期処理
- **AsyncTask** を使用してUI非ブロック
- 生成中は `isloading = true` でローディング画面を表示
- 完了時に `task.get()` で結果（成功/失敗）を取得

#### ビジネスロジック
- 類似度（Difference）の計算
- 一致率の円グラフ表示
- キャラクター選択時のプレビュー更新

### Scene4（再生画面）

#### 目的
- 生成済みの覚え歌音声を再生
- 歌詞の確認・音声の削除

#### UI要素
- **ファイルリスト** - `App/Voice/` 内の音声ファイル一覧
- **歌詞テーブル** - 選択した音声の歌詞表示（対応楽譜から取得）
- **ボタン**:
  - **「再生」** - 音声再生
  - **「停止」** - 再生停止
  - **「再度再生」** - 最初から再生
  - **「削除」** - ファイル削除
  - **Scene1/Scene2/Scene3への遷移ボタン**
- **チェックボックス**:
  - **「伴奏を同時再生」** - 対応する伴奏（Instruments/）を同時再生
- **スライダー** - 音量調整

#### 状態
- `VoicefileNames`: 音声ファイル名リスト
- `selectedVoiceFile`: 選択中のファイル名
- `audio` / `audio2`: 音声・伴奏のAudioオブジェクト
- `playing`: 再生中フラグ
- `checked` / `checked2`: チェックボックス状態
- `value1`: 音量スライダー値
- `table`: 歌詞テーブル
- `listBoxState`: ファイルリスト選択状態
- `textAreaEditState`: テキストエリア編集状態（歌詞表示用？）

#### イベント
- **ファイル選択** → 歌詞テーブル読み込み・表示
- **「再生」ボタン** → 音声再生（伴奏同時再生オプション）
- **「停止」ボタン** → 再生停止
- **「削除」ボタン** → ファイル削除確認 → 削除実行
- **音量スライダー** → 音量調整

#### データ処理
- **音声ファイル一覧取得**: `App/Voice/` 内のファイルをリスト化
- **歌詞読み込み**: 対応する楽譜（`App/CreatedScores/`）から歌詞を抽出し、テーブル表示
- **伴奏同期**: ファイル名から楽曲名を抽出し、対応する伴奏（`App/Instruments/`）を読み込み

#### ビジネスロジック
- ファイル名解析（"語句名-楽曲名-キャラ名.wav"から楽曲名を抽出）
- 伴奏の同期再生

## Scene設計の方針

### UIとビジネスロジックの分離
- **Scene1, CreditScene**: UIのみ（ビジネスロジックなし）
- **Scene2**: データ入出力のみ（検証は最小限）
- **Scene3**: 複雑なビジネスロジック（生成処理）は `JSONHandler`, `LyricsProcessor`, `VoiceVoxSynthesizer` に委譲
- **Scene4**: 再生・ファイル管理のみ

### 状態管理
- 各Sceneは独立した状態を保持
- Scene間でのデータ共有は **ファイルシステム経由**（CSV, JSON, WAV）
- シーン遷移時に前のシーンの状態は破棄される（再度開いた場合はファイルから読み込み）

### 非同期処理
- **Scene3のみ** 非同期処理を使用（音声生成が時間がかかるため）
- 他のSceneは同期処理

### エラー処理
- 入力エラー（Scene2）: 赤色表示で警告
- 生成失敗（Scene3）: メッセージボックス表示
- ファイル読み込み失敗: 空のリスト表示（エラー表示なし）

### 今後の拡張方針（想定）
- 新しいSceneを追加する場合: Main.cppに登録、既存Sceneに遷移ボタンを追加
- Sceneの複雑化を避けるため、ビジネスロジックは別モジュールに分離する
